# House Price Prediction System

## Overview
使用机器学习模型预测房价，并构建完整前后端系统。

## Models
- Linear Regression
- Random Forest
- XGBoost（最佳）

## Performance
| Model | R² |
|------|----|
| Linear | 0.79 |
| RF | 0.89 |
| XGB | 0.90 |

## Features
- 房价预测
- 输入校验
- 误差范围（RMSE）
- 市场价格判断
- 预算推荐
- Explain AI

## Tech Stack
- Python (sklearn, xgboost)
- Flask
- React
